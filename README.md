# Viral Classifier Agent – User Guide

## What is this?
An AI agent that analyzes why content goes viral, creates a detailed report, and then generates a new post designed to go viral based on real metadata factors.

## How to Use

### 1. Deploy the Agent
Copy the contents of `viral_classifier_agent.md` into any AI agent platform that supports custom instructions (e.g., ChatGPT with custom GPT, Claude Projects, Open Interpreter, or LangChain agent).

### 2. Provide Input
Send the agent a message containing:
- **The content to analyze** – a link, text, or description of a post/video.
- **Optional:** Platform name.
- **Optional:** Any known metrics (likes, shares, date).

**Example input:**
> Analyze this tweet: “The way she explains quantum physics in 30 seconds using only a slinky is insane 🤯” – 50K retweets, posted yesterday on Twitter.

### 3. Receive Outputs
The agent will return:
- `viral_report_<timestamp>.md` – Full breakdown of viral factors.
- `generated_viral_post.md` – New post you can publish.
- `metadata_schema.json` – Structured data of what was found.

### 4. Use the Generated Post
- Edit the `generated_viral_post.md` to match your brand voice.
- Post it on the recommended platform.
- (Optional) Run the agent again on your new post for iterative improvement.

## Example Workflow

1. **You:** “Classify this Reddit post: ‘I quit my job to bake bread for my cat – here’s what happened’ – 8K upvotes, 500 comments”
2. **Agent:** Analyzes emotional drivers (surprise + humor), relatability, hook strength.
3. **Agent:** Returns report showing “unexpected life choice” as #1 viral factor.
4. **Agent:** Generates new post: “I replaced my morning coffee with yelling affirmations at my houseplant – the glow-up is unreal 🪴”
5. **You:** Post it → track engagement.

## Tips for Best Results
- Provide at least one engagement metric (likes, shares, comments).
- Include the first sentence of the post – hooks matter most.
- For video, describe the first 3 seconds.
- Run analysis on **both viral and non-viral** posts to compare.

## Agent Limitations
- Cannot access live social media APIs (use manual copy-paste of metrics).
- Virality score is probabilistic, not guaranteed.
- Platform algorithms change; re-run analysis every 3 months.

## Customization
You can edit `viral_classifier_agent.md` to:
- Add platform-specific rules (TikTok “save” rate > share rate).
- Change the virality scoring weights.
- Add a section for ad spend recommendations.

## Files Generated by Agent
| File | Purpose |
|------|---------|
| `viral_report_*.md` | Read this to understand *why* something worked |
| `generated_viral_post.md` | Copy-paste this into your social scheduler |
| `metadata_schema.json` | Use for training your own classifier |
